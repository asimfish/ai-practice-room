# 模拟验收答案与真实执行边界

这是本站原创文字候选的参考答案，不是实际生成视频的观察结果。先独立填写缺陷CSV再对照；没有对应媒体，不能填写“已观看”“任务通过”或捏造任务ID。

- SIM-01 / S03围裙：若首帧深绿、动态才变蓝，视频层问题。本人有局部视频编辑可只恢复颜色，并全镜回查脸/衣服/光/音；没有编辑则重做这一镜。图片重绘只能修图片，不能自动修原视频。
- SIM-02 / S06包带：先查原始参考图/主体绑定是否已反；动态才反则减少动作或整镜重做，保留左肩到右腰不变。不能同时换模型、衣服和动作再声称找到原因。
- SIM-03 / S05开书：关键道具状态错误，本剧无开书动作；不能为凑时长快切遮住。先查首尾帧，不正确先修图；正确则限制动态/整镜重做，书全段闭合。
- SIM-04 / S03静帧错位：输入层/构图错误，先修单镜首帧与视线，不先付费动起来。林岚右看左，许远左看右，同侧轴线。
- SIM-05 / D12漏“没”：声音改变因果，优先重录或重做该句音视频，再校字幕；只改字幕会留下相反的声音。
- SIM-06 / D10嘴错：声音准确但口型失败，可兼容口型重做；或改林岚动态听话反应/书插镜承载许远声音。后者记“覆盖改法，口型未修复”。
- SIM-07 / 连接错误：检查两段首帧位置、视线与剪辑覆盖。若实际跨线，重设计该段或补位置交代；单镜稳定不证明连起来正确。
- SIM-08 / 坏尾帧：此前关键动作完整时可以试缩出点并回查稳定接点；有效时长因此缩短，不能仍把6秒全算合格。若台词/反应被截断，不可只剪掉。

请求单候选A没有抬眼：动态任务没实现，失败；候选B围裙变蓝：身份/服装连续性失败。漂亮画质不能抵消关键缺陷。

修复记录至少写镜号、时间点、预期/实际、原因假设、唯一变量、保留项、原版/新版本和前后段回查。原因未经验证只叫假设。

实际影片质量标准槛：身份/服装/包带稳定；同侧轴线与正确视线；闭合旧书状态连续；动作/台词有因果；准确说话者与台词；清楚嘴部可见时口型可接受；首尾和对白可剪；竖屏实际输出与手机完整播放正常。

停止线：每镜最多2次、下一请求超预算、报价/单位/权限不清。同一关键缺陷持续时停下重设计更简单动态，不无限重跑全剧。

静态参考、静态配音、模型宣传、模拟判读均不证明短剧已制作。毕业仍需本人实际主要AI动态叙事、真实声音/字幕、剪辑、完整导出与当前发布前核对；本课不代发布。
