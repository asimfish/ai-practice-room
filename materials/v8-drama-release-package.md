## 建议保存的文件

- 01-创作说明：受众、主题、主角目标、冲突、结局、总集数与AI参与范围。
- 02-剧本：原始稿、最终稿及本人修改记录；改编时另列上游授权。
- 03-角色卡：角色固定外貌/服装/道具/声音、参考图及素材ID。
- 04-分镜：每集镜头编号、实际时间、画面动作、台词、声音、修订记录。
- 05-素材索引：图/视频/声音/音乐/字体/模板逐项来源、条款日期、用途授权、证明文件位置。
- 06-项目副本：剪辑工程、字幕、本人可合法保存的源素材，保留原稿。
- 07-终版：每集可播放导出文件、封面；文件名带集数与版本。
- 08-审片记录：完整播放、手机复看、同伴盲看与时间码修改；前版另存。
- 09-手续记录：当前分类及官方依据、真实投资与口径、资格/前置手续、审核及实际适用编号。
- 10-发布记录：本人实际提交状态、抖音链接、真实发布时间、公开标注检查；未做就未执行。
- 11-复盘：允许处理的去身份反馈、可见数据口径、真实成本/失败重试/时间与下一版决定。

## 交付检查

- [ ] 终版是本人实际导出的文件，可重新打开完整播放。
- [ ] 项目能找到源素材；移动目录后先检查缺失素材，不假定工程副本一定完整。
- [ ] 文件名、集数、内容、字幕与发布信息一致，旧版清楚标识。
- [ ] 来源证据可逐项定位；涉及保密材料仅在本人获准范围保存和提交。
- [ ] 质量、手续、提交和上线状态分别有证据；未知未写成通过。

本清单是本站原创教学建议，平台实际格式、材料数量与资格要求以本人当前适用规则为准。
