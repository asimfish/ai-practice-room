# 真实预算模板与原创模拟答案

CSV中的“练习单位”及40/8/6/7等数字全部是本站原创模拟输入，不是人民币、美元、任何服务积分价、免费额度、优惠或实测账单。不能把这些值复制到真实报价栏。

## 提交前规则

可用余额 = 本人总上限 - 已结算消耗 - 已提交未结算的保留额。

必须同时满足：

1. 数值明确、非负，单位完全一致。
2. 本次预计消耗不超过可用余额。
3. 本镜已提交次数小于2（提交即计次，不能因排队/失败自行归零）。
4. 当前报价、素材权利和必要能力清楚。

报价未知、单位不同、预算不足、次数到限时停止。排队不是免费；失败是否返还按服务真实账单核对。单次估计为0只有本人确实核对为0才可填，不用“可能免费”代替报价。

## 四个模拟答案

- SIM-A：余额40-8-6=26；7≤26，已请求1次<2，单位明确相同。预算规则READY。它只允许模拟下一请求，不等于真人已支付或作品已通过。
- SIM-B：余额40-38-0=2；4>2，STOP，下一请求超预算。
- SIM-C：余额32；5≤32，但已请求2次达到上限，STOP。钱够也停止。
- SIM-D：余额32；本次报价空白，STOP。不能用0补空白。

课程离线预算函数只计算这些规则，不读账号、不查价格、不提交生成。服务之外的总预算授权、素材权限和工具能力也要由本人核对。

## 草案与最终稿

先用当前可用档判断角色/动作/对白，通过后再考虑高分辨率。升档是否重生成、另扣费或保留画面由工具核对，不保证无损升级。静态配音可预演节奏，但真实毕业要主要AI动态叙事、声音字幕、剪辑和完整导出检查。

## 高级选修的成本边界

ComfyUI/Wan2.2需要已有相容宿主、Python/PyTorch/GPU环境、节点、文本编码器/VAE/模型文件。ComfyUI官方所述5B卸载路线8GB，与原作者CLI示例至少24GB是不同执行条件；不能外推到14B或手机。代码/模型/第三方节点各自核许可，托管云核费用、上传权限和保存期限，本地核硬件、电力、内存和时间成本。本站没有安装、下载模型或运行这些路线。
