# 手机接续、局部改教案与回电脑签收

本卡为原创练习单，实际会话、工作台、手机连通与文件修改全部尚未运行。先完成同目录只读核对，再使用下列请求。

## 项目身份核对

- 日期与当前账号：本人填，公开作品只保留必要的匿名说明。
- 真实执行电脑：待填。
- 电脑是否在线、daemon是否运行：待填。
- workspace与绝对路径：待填。
- source_type与Codex会话名称/可识别标记：待填。
- 使用的独立认证配置名：待填，不写凭据内容。
- 输入文件三个：待填。
- File与Terminal面板是否指向同一项目：待填。

目录和来源依据 [创建实例指南](https://memory.whalent.com/guide/agent-create/)，凭据隔离依据 [ChatGPT登录指南](https://memory.whalent.com/guide/chatgpt-login/)。客户端入口、按钮与账户能力按实际界面核对；认证成功还要通过只读任务确认文件来源。

## 电脑端只读请求

```text
请报告当前工作目录和这段Codex会话的执行环境，列出source.md、lesson-v1.md、worksheet-v1.md是否存在。只概述source.md的目标、词表、课时与输出约定，不修改、不删除、不发送。找不到文件请写缺失，不猜其他电脑的路径。
```

把返回的目录和文件与本机逐项对照。不同则先定位账号、设备、凭据、workspace；不要开始教案生成。

## 电脑端 v2 请求

```text
根据source.md检查两份v1，整理为lesson-v2.md、student-v2.md、teacher-key-v2.md。时间按5+8+10+8+4=35分钟；每段有教师话术、学生动作、材料和达标信号。纠正原稿单复数错误并解释；学生文件不包含答案。保留原件，不新增时态、地点介词和词表外内容。报告真实路径和未检查项，不发送、不共享。
```

人工打开后记录：35分钟是否相加正确；题目和答案是否正确；学生文件是否藏答案；是否使用未知词汇；教师话术是否能试讲。

## 手机端只改一个环节

手机浏览器登录同一账号，左上角抽屉切换机器、workspace、对话。核对电脑最后一条消息后发送：

```text
继续这同一段会话。只改lesson-v2.md中23–31分钟的两人任务：A描述前先数物品，B听后画图并用同样句型读回，A揭开物品一起核对，再交换角色。总时长仍8分钟，保留词表和其他段落。先列修改计划与影响文件，再按当前实例权限流程另存lesson-v3.md；不覆盖v1/v2，不发送给别人。报告实际路径、检查范围和未完成项。
```

手机操作不能替代检查执行设备在线。手机锁屏也不能用于判断任务是否已完成。浏览器/PWA和原生App功能不同；本卡默认手机网页，不要求App通知或系统分享。

## 手机结果记录

- 手机发出的要求是否出现在电脑同一会话：待填。
- 当前任务状态与最新输出：待填。
- 实际文件路径：待填。
- 手机是否能查看/下载该文件：待填。
- 文件不能查看的具体原因：待填。
- 需要处理的权限请求及范围：本人核对后记录，不填自动同意所有操作。
- 未检查项：待填。

## 回电脑签收

1. 实际打开v3，对照v2逐段看。
2. 只有两人任务的动作说明改变，时长仍35分钟。
3. v1/v2仍在，学生题目和教师答案分开。
4. source词表和目标没有变化。
5. 项目清单的路径能找到对应文件，已检查与未检查准确。

每项写通过/未通过/未运行。教师仍需根据真实学员调整，不把远程写文件通过等同课堂效果通过。
