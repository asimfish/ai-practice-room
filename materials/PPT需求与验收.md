# PPT 需求与验收单

AI练习生 · 2026-10-09。方括号替换为实际内容。

## 需求

- 主题：[我的 AI 第一课]
- 听众：[零基础亲友]
- 用途：[10分钟分享]
- 页数：[8页]
- 格式：[16:9，可编辑PPTX + PDF + 讲稿]
- 材料：[已审核课程笔记]
- 模板：[自己拥有或有权复用的PPTX]
- 模板意图：[沿用原页结构填内容 / 提取设计创建新稿]
- 保留：[主题色、字体、页眉、图形]
- 必含：[Kimi小任务、完整提问、文件核对、Skill、三个实践方向]
- 不应出现：[无来源数字、真实学生信息、商家广告、收益承诺]

## 8页示例结构

1. 今天学什么：完成一件真实小事。
2. 一个任务的四项说明：背景、目标、限制、交付。
3. Kimi练习：从初稿到修改。
4. 上传材料：先确认读到什么，再核对原文。
5. 电脑工作区：原稿和练习副本分开。
6. Skill：重复方法，需要宿主和依赖。
7. 英语、PPT、视频：选一个专题。
8. 今天的作业：成果、检查、保存。

## 制作步骤

先审核大纲；先做3页小样；检查可编辑性与模板结构；完成全稿；定向修订；全屏试讲；导出PDF；重新打开检查。

## 验收

- [ ] PPTX能打开，标题能改。
- [ ] 每页一个重点，没有长文堆砌。
- [ ] 无文字溢出、重叠、图片拉伸、低对比。
- [ ] 数字、事实和来源已核实。
- [ ] 模板与素材有权使用。
- [ ] 试讲时长合适。
- [ ] PDF重新打开后页数和内容正确。
- [ ] 原模板、v1与v2有独立备份。
