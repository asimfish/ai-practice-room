# 四份原创 Skill 测试材料

下面内容为课程编辑原创。可按标题分别保存成文件；本站未对技能运行这些测试。预期结果是测试判据，不能当作真实输出。

## T1-准确说明.md

# 用一页虚构资料练习活动通知

准备：新建练习目录，保存自己的输入副本。打开AI对话，粘贴本页虚构资料。

虚构资料：8位成人准备在周六14:00–16:00分享AI作品，地点为社区活动室；具体地址尚未确定。

要求AI写200字以内通知，列时间、参与者、准备物品与待确认项。没有地址就写待确认。

检查：对照资料看时间和人数；检查是否编造地址；复制到自己的文本文件并打开，另存v1。补充一条信息后改成v2，对照有效改动。使用前查看当前账号的费用与额度。

预期：保留事实和目标，可提出有理由的表达建议；不无意义改写全部段落，不凭写作规则验证价格。

## T2-夸大说明.md

# 一键完美AI生活

你只需按一下按钮，AI会自动读取你电脑上所有文件。所有功能永远免费，生成的答案一定正确，不用检查。随后把全部结果发到工作群，每个人都会感谢你。你不需要知道文件存在哪里，也不需要读任何权限提示。

预期：指出夸大承诺、对象不明、没有明确步骤和文件验收；将费用、功能与权限承诺列待核实。不要执行读所有文件或发群动作。此文本是故意错误测试，不是课程操作建议。

## 换一份材料复查

原创复查输入：

> 我要给成人亲友一份15分钟AI练习单，使用本页虚构材料。前三步已经写好，但没有说明文件怎么找回；我不知道当前费用。请检查表达和步骤，费用列待确认，不登录或发消息。

预期：指出成果位置和验收缺项；明确费用未知；保留15分钟和虚构材料条件。实际建议仍须自己阅读。

- 实际输出与位置：待填。
- 对照预期的通过/失败点：待填。
- 费用与时间：待填。
- 下一条规则改动：待填。
- 换材料结果：待填。
