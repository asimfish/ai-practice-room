# 三份标准任务单：原创输入包

这是虚构练习材料，不包含真实学生、客户或活动安排。本站未用 Harness 生成文档。本页用于保存输入；请复制到自己的练习目录，先处理 H01，再处理 H02、H03。

## 文件准备

建议目录：`AI练习-Harness批量/input/` 与 `AI练习-Harness批量/output-v1/`。输入放本文件和编号清单，输出另存。你选择的真实工作区路径以自己的电脑为准。

每份输出按固定六节：对象、可观察目标、分钟流程、材料、待确认项、交付验收。保留输入编号；日期、房间、教材页码、学生情况和答案依据缺失时不补造。

## H01：动物能力复习

对象：虚构10岁学习者；已学 bird、fish、fly、swim、jump。

课时：20分钟。主题：can / can’t。目标：能用已学词说出2句动物能力句。材料：词卡、纸。没有提供实际学生识词观察，任务单应将其列为教师需确认项。

编辑建议骨架：3分钟识词卡，5分钟示范，8分钟动物与动作配对说句，4分钟出口检查。总计20分钟。示范句可用 `A bird can fly.` 与 `A fish can swim.`。只使用本词表和can结构。

输出：`H01-任务单.docx`。验收：六节完整，时间合计20，目标能观察，英语正确，文字可以编辑。输入原件保留。

## H02：借入和借出

对象：虚构初一学习者；已学 pen、book、bag。

课时：25分钟。主题：borrow / lend 的方向。目标：完成2道方向判断题。材料：一支笔，用实物演示。不添加新时态，不需要AI生成手部视频。

编辑建议骨架：4分钟说自己的理解，6分钟教师用笔示范，10分钟两人交换与判断，5分钟出口题。总计25分钟。

可用题目：

1. `I borrow a pen from you.` 谁借入？教师答案：I。
2. `You lend a pen to me.` 谁借出？教师答案：you。

待确认：学员能否理解两个代词在示范中对应谁。通过实物交换核对，不仅让学员背中文定义。

输出：`H02-任务单.docx`。验收：六节完整，25分钟，借入与借出正确，学生题目和教师解释清晰可辨。

## H03：成人AI学习分享

对象：虚构8位成人。课时：45分钟。目标：每人说明一项作品和一项待改进点。材料：自己的练习电脑。

举办日期与房间尚未确定，没有报名方式或活动室地址。不能编造“10月17日”“201室”等信息。

编辑建议骨架：5分钟准备，15分钟分组介绍作品，15分钟互提修改建议，10分钟每人写下一步。总计45分钟。各组可先交流，再让每个人完成书面下一步；不要声称45分钟一定足以让8个人逐人长篇演讲。

输出：`H03-任务单.docx`。验收：六节完整，45分钟，人人有可观察成果，日期和房间明确标待确认。

## 本批交付

三份任务单，加 `manifest.csv` 和 `验收说明.md`。文件名是教学约定，不是软件的原生自动命名功能。没有生成真实文件、没有打开检查、没有课堂验证时，分别写清。

正式签收前，人工从每行清单打开文件，读一遍、复算时间、试改一处文字。遇到问题只修对应编号，另存 `output-v2/`，不要反复覆盖全部文件。
