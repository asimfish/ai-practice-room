# 六文件命名练习：从空文件夹准备与逐项预览

以下全部原创虚构。ZIP只含6个UTF-8 TXT，没有脚本或可执行文件。本课程仅制作材料，没有让Harness/WorkBuddy整理文件；预览和人工决定是教学参照。

## 建文件夹与核对输入

在电脑创建 `AI自动化练习/input`、`output`、`records`。将 `v7-practice-file-inputs.zip` 中6个TXT解压到input，output先保持空白。输入是练习副本，ZIP和本材料留作恢复来源。不会解压时，用纯文本编辑器按下面6段创建同名TXT；注意不要另存成.txt.txt。

6个确切原名：会议记录.txt；notice-draft.txt；无日期教案.txt；2026-10-08_词卡_01.txt；notes-v1.txt；视频记录_初稿.txt。**原名全部不同**；冲突发生在规则计算后的目标名。

## 命名规则与未执行的预览答案

只读正文的日期、主题、序号，目标名为 `日期_主题_序号.txt`。不使用电脑当前日期或文件修改时间替代缺失日期；不改正文、不删输入、不覆盖文件、不访问工作区之外。先预览，不执行。

- 会议记录.txt → 2026-10-09_通知_01.txt；目标冲突，指出notice-draft.txt。
- notice-draft.txt → 2026-10-09_通知_01.txt；目标冲突，指出会议记录.txt。
- 无日期教案.txt → 待确认_教案_02.txt；缺日期待确认，必须本人决定是否接受待确认标签或补日期。
- 2026-10-08_词卡_01.txt → 同名；已合格，仅在批准后向output复制，输入保留。
- notes-v1.txt → 2026-10-09_教案_01.txt；正常。
- 视频记录_初稿.txt → 2026-10-09_视频_01.txt；正常。

预览6行：正常2、已合格1、冲突2、缺日期1。未批准前output应为空。冲突行不能使用自动覆盖或自行添加序号；缺日期不能猜日期。

## 一组人工确认示范：实际仍由本人决定

假设本人明确批准：会议记录沿用通知01；notice-draft使用通知02；无日期教案仍以待确认标签命名；其余按规则复制。此时6个输出目标应互不相同：

```text
2026-10-09_通知_01.txt
2026-10-09_通知_02.txt
待确认_教案_02.txt
2026-10-08_词卡_01.txt
2026-10-09_教案_01.txt
2026-10-09_视频_01.txt
```

序号02只是目标命名的批准决定，不擅自修改notice-draft正文的序号字段。处理清单注明“按本人确认的目标名例外”，下一次不能自动将这种例外当默认规则。若本人决定补日期或不同序号，按真实决定调整并重新预览。

写 `records/处理清单-v1.csv`，字段可为original_file、suggested_file、decision、actual_output、status、reason。再交验收记录.md。生成后逐个打开，确认输出6份、正文未改、输入6份仍在；不存在的文件不能填为已完成。

## 第7文件：迁移与异常测试
