# 同一can/can’t题库：教案、展示与反馈的选题关系

本站原创虚构课堂材料。输入沿用 `英语教案练习包.md` 的学生A、词表和5题题库；本页说明选题和人工答案。未开展真实课堂，没有学生实测结果。

## 40分钟教案与Word/PPT共用3题

教案目标为学生能说出3句能力表达，课末小测用题库**原题1、原题3、原题5**。保持原题号，不重编为新1/2/3。原题2和原题4留作补充；原题库仍完整保留5题。

学生课末小测：

```text
原题1：A fish can ___.（swim / fly）
原题3：A fish ___ fly.（can / can’t）
原题5：用can和已学词表造一个句子。
```

教师答案与判定：

- 原题1：swim。检查已学动作词与本练习的一般能力含义。
- 原题3：can’t。检查是否保留否定及动词原形；一般例句不是完整动物分类结论。
- 原题5：开放作答，如 `A cat can run.`。接受词表内合理能力句；检查主语、can后动词原形和句子含义。不限定只有一个范例。

40分钟教案大纲5+8+10+12+5：动作词热身、示范、引导练习、画动物并说句、上述课末小测。每环节另写教师话术、学生动作、材料和可观察达标信号。教师仍按实际学习者调整；分钟总和不证明课堂一定可完成。

Word保留教师答案独立章节；3页PPT为目标与情境、can/can’t示范、原题1/3/5。第三页学生放映不显示答案。参考PPT只提供可编辑设计，其原第三页题目应替换，不能误认为就是本次选题。

## 分层练习是另一份15题产物

`english-materials`要求基础／标准／提高各5题，共15题。它们由学习者生成并逐题核对；不能把原题库的5题或本课选出的3题当作已交付15题。保持同一目标，改变支持程度或已学情境，不增加语法。题号可使用基础1–5、标准1–5、提高1–5，明确与原题号不同。

## 反馈课使用完整5题虚构作答

以下对应原题库及其中的虚构作答，不是3题课末小测的真实课堂结果：

- 原题1：教师swim；虚构作答swim，符合本题。
- 原题2：教师can；虚构作答can，符合本题。
- 原题3：教师can’t；虚构作答can，漏掉否定；可能是未理解can/can’t，也可能阅读时漏看，需检查确认。
- 原题4：教师“兔子会跳”；虚构作答相同，符合本题。
- 原题5：开放句须动词原形；虚构作答 `A cat can runs.`，应修为 `A cat can run.`。可能混用第三人称词尾，不能据此诊断学习问题。

可检验的5分钟补救：1分钟用手势复述can/can’t；2分钟判断 `A fish can swim.` 与 `A fish can’t fly.`；2分钟按词卡说一条肯定、一条否定，检查动词原形。记录实际表现后再判断下一步；这只是教学设计，未试教。

使用反馈时引用题号和作答证据，给具体表扬、改进及一个可操作练习。以后若产生真实匿名作答，另记来源和日期，不替换或伪装本页虚构数据。
