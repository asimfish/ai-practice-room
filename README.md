# AI练习生

中文 AI 学习与实践课程，从工具入门到独立制作作品。

网站：https://asimfish.github.io/ai-practice-room/

本仓库发布第十三版网页：90课、72个提示词模板，三个定制跟做流程（PPT 9步、AI短剧10步、英语备课9步），每步有输入材料、建议文件、下步用法和常见问题；本人记录的结果进入后续提示词。图文、视频入口、操作示范和原教程位于对应课程与制作步骤。

主线：Kimi App／CLI → DeepSeek Harness → Codex → 配置和调用 Skill；WorkBuddy、Claude Code 选修。学会提要求和检查，再填自己的主题与材料，制作一个实际作品，修改后换需求复做。

网站整理学习步骤、需求和可复制提示词。下载的制作记录为文字；真实PPTX、MP4、Word/PDF在学习者自己的工具中制作、打开和检查。默认故事和素材是教学示范，填写与勾选不能替代真实作品。
