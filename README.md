# AI练习生

面向零基础亲友的中文 AI 实用课程。

网站：https://asimfish.github.io/ai-practice-room/

本仓库发布第十版网页：88课、70个提示词模板、125条来源、33份实战、103份练习材料。图文与演示位于对应部分及操作步骤，适用案例在课程练习内展开。

从基础9课开始，再选择英语教学、PPT、AI短剧、WorkBuddy、自动化或Anygent。案例素材是教学示范，真实工具结果与发布状态由学员另行验收。
