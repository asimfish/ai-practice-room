# AI练习生

中文AI学习与实践课程：工具入门 → 协作方法 → 选择自己的作品 → 检查与独立复做。

网站：https://asimfish.github.io/ai-practice-room/

第十四版（14.0.0）：90课、72个提示词模板，PPT9步、AI短剧10步、英语备课9步。三个项目均提供本人需求的Agent任务文件与明确的实际操作，要求在自己的Codex/Harness等具备本地能力的工具里读取材料、调用真实工具、生成版本文件、检查并修改。94条具体问题/处理保留在各步骤内；图文、原教程和视频随课查阅。

## 实际执行

视频按本人条件选择：入门在自己可用的视频网站生成原片，再交回Agent；进阶使用个人官方MiniMax API和本地工具包（固定v2协议），校验单镜请求、本人确认费用、单次提交、查询同任务、下载、以真实素材/声音/SRT运行FFmpeg输出MP4。无API路线不要求API报价。默认模板缺真实报价/素材时会停，不提供共享账号、充值或自动发布。

本地工具包与两个练习目录在materials/，网页可下载当前需求的Agent任务文件。网页是静态教学与任务整理，没有模型执行后端，也不接收API Key。密钥只由本人在本机配置。

## 示范与证据范围

本轮作者Agent实际生成了3页原生可编辑PPTX/同版PDF，以及3页DOCX/PDF英语微课，并渲染检查。视频提供实际剪辑工具输出的8秒测试MP4（非AI短剧）；API请求/状态异常以模拟响应测试；公开官方示例下载做过真实传输验证但未再分发。

本人账户认证、收费视频生成、实际AI角色与口型质量、学员Office编辑、课堂效果和公开发布不在本轮实测范围，不以示范或勾选替代学员作品检查。真实成品在各自的工具中生成、打开与检查。

## 维护与发布

根目录为审核后的静态发布文件；既有release/v10分支根目录由GitHub Pages发布。保留.nojekyll和原有学习记录键。维护源、校验和独立离线导出由原教学项目管理。各产品条件以当前官方说明为准，原资料核对日期随课标明，外部教程与实时Skill目录需要网络。
