# AI练习生

中文AI学习与实践网站：工具入门 → 协作方法 → 制作自己的作品 → 检查、修改与独立复做。

网站：https://asimfish.github.io/ai-practice-room/

当前版本：15.0.0 · 2026-10-10。90课、72个提示词模板，PPT9步、AI短剧10步、英语备课9步。

## 向原作者继续学习

189条去重的原教程、原作者博客、视频原页和Skill／项目资源。在90课、7个工具阶段、28个项目步骤及13专题内提供明确对应入口。优先卡片展示学什么、学完练什么；更多资料按步骤展开。核对日期、语言、准备条件和实际核对范围在每条资料内保留，历史资源不自动升级为本轮实测。

每步可继续按具体问题查原资料、检查版本与许可、做小范围测试并整理自己的方法；提供可复制的探索提示词及下载记录。没有合适视频的步骤明确标出图文路径与查找方法，原作者的虚拟实操、教学视频和成片展示按实际性质说明。外部视频和目录需要网络与原平台条件。

## 实际执行与证据边界

三个定制项目保留本人需求的Agent任务下载、练习目录和94条具体问题处理。作品在本人Codex／Harness等具有本地能力的工具里生成和检查；网页是静态课程和任务整理，不接收API Key，也没有共享的模型执行后端。

视频入门可在本人可用的网站生成原片后交回Agent；进阶可用个人MiniMax API与本地工具包，确认费用、单次提交、查询同任务、下载并用真实素材剪辑。示范包含作者实际生成并检查的3页PPTX／PDF、3页DOCX／PDF，以及8秒剪辑工具测试MP4（非AI短剧）。本人账户认证、收费生成、实际角色口型质量、课堂与公开发布未在本轮执行。
